# 🚀 Modern To-Do List Web App

A clean, responsive, and feature-rich To-Do List application built from scratch using **Vanilla JavaScript**, **CSS3**, and **HTML5**. Designed with a modern UI and persistent storage to streamline daily task management.

## ✨ Features
* **Add Tasks:** Quickly add new tasks with empty-input validation.
* **CRUD Operations:** Dynamically create, update, and delete individual tasks.
* **Task Completion:** Toggle task completion status with a visual line-through effect.
* **Bulk Actions:** Complete all tasks or clear the entire list instantly with a single click.
* **Data Persistence:** Automatically saves tasks, completion states, and local changes using browser `localStorage`.

## 🛠️ Tech Stack
* **HTML5** - Structure and semantic markup
* **CSS3** - Modern styling, Flexbox layout, and soft pastel UI palette
* **JavaScript (ES6+)** - DOM manipulation, event handling, JSON serialization, and state management
